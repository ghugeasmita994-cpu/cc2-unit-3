Gym Membership Management System using Linked List – maintain member records, renewals, searches, and deletions.
Gym Membership Management System using Linked List


1.Problem Statement

To create a simple Gym Membership Management System using a Linked List to store and manage gym member details

2.Objectives

1) To add gym member details.
2) To display member records.
3) To search for a member.
4) To renew and delete membership records.

3.algorithm

1) Start the program.
2) Create a linked list to store member details.
3) Display the menu of operations.
4) Accept the user's choice.
5) Perform the selected operation:
    Add a member.
    Display all members.
    Search for a member.
    Renew membership.
    Delete a member.
6) Display the result of the operation.
7) Repeat the menu until the user selects Exit.
8) Stop the program.


4.Algorithm Explanation


Start: Start the program.
Create Linked List: Create a linked list to store gym member details.
Display Menu: Show the available operations.
Accept Choice: Enter the user's choice.
Add Member: Enter and store member details.
Display Members: Show all member records.
Search Member: Find a member using their ID.
Renew Membership: Add extra months to the membership.
Delete Member: Remove a member's record.
Repeat: Show the menu again for another operation.
Stop: End the program when Exit is selected.
